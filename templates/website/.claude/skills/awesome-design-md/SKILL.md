# awesome-design-md

One folder per brand in `design-md/<brand>/DESIGN.md` (Stripe, Linear, Vercel, Notion, Apple,
Figma, Spotify and about 70 more). Each file describes a design language: theme, colour palette
and roles, typography rules, component styling, layout, elevation, responsive behaviour, and a
prompt guide.

How to use:
1. `ls design-md` to see the brands. Read the one or two the user points at.
2. Take structure and principles, not the brand. Never ship another company's identity,
   logo or copy.
3. If the project has its own design (Figma, Penpot), write the project's own `DESIGN.md` at the
   repo root in this same section layout, from that design, and build against it.
